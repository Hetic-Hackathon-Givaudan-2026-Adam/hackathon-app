# HETIC Hackathon Givaudan 2026

## About
This repository contains our team's project for the HETIC Hackathon Givaudan 2026.

## Git Workflow
We use the following branches:
- `main`: Stable version.
- `develop`: Integration branch.
- `feature/*`: New features.
- `hotfix/*`: Urgent fixes.

## Collaboration
All changes must be submitted through pull requests. Team members should review changes before merging into protected branches.

## Documentation
Technical decisions and project documentation are stored in the `docs/` directory.
